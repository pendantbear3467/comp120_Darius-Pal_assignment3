# comp120_Darius-Pal_assignment3

A simple browser-based **Task Manager** application built with HTML, CSS, and JavaScript.

## Features

- Add new tasks using the input form
- Mark tasks as complete (or undo completion)
- Delete tasks
- Tasks are saved in `localStorage` so they persist between page refreshes

## Usage Instructions

### Running the App

1. Clone this repository:
   ```bash
   git clone https://github.com/pendantbear3467/comp120_Darius-Pal_assignment3.git
   cd comp120_Darius-Pal_assignment3
   ```
2. Open `index.html` in any modern web browser (no build step or server required).

### Adding a Task

1. Type a task description in the **"Enter a new task…"** input field.
2. Click the **Add Task** button (or press **Enter**).
3. The task will appear in the list below.

### Completing a Task

- Click the **Done** button next to a task to mark it as completed (text will be struck through).
- Click **Undo** to mark it as incomplete again.

### Deleting a Task

- Click the **Delete** button next to a task to remove it permanently.
